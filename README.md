# DuiLib
DuiLib 基于Bjarke Viksoe的DirectUI库，使用 Direct2D/Direct3D 进行渲染。

## 相关项目

- [原始 DirectUI](http://www.viksoe.dk/code/downloads/directui_src.zip) - Bjarke Viksoe 的原始实现
- [duilib/duilib](https://github.com/duilib/duilib) - 官方 duilib 项目
- [qdtroy/DuiLib_Ultimate](https://github.com/qdtroy/DuiLib_Ultimate) - 增强版本
